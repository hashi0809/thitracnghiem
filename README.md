# thitracnghiem

Web ôn tập và thi thử trắc nghiệm, chạy bằng 1 file HTML duy nhất, không cần backend.

## Cách dùng

Mở `index.html` là chạy, hoặc deploy lên Vercel (Vercel sẽ serve `index.html` ở trang chủ).

- Nhập file câu hỏi `.txt`, `.csv`, `.docx`, `.xlsx` để tạo môn học mới, hoặc dán nội dung trực tiếp.
- Mở lên đã có sẵn 2 môn mẫu: Kiến thức chung và Tin học cơ bản, bấm Luyện đề nhanh là làm được ngay.
- Chế độ Ôn tập hiện đáp án và giải thích ngay từng câu, chế độ Thi thử có bấm giờ, trộn câu hỏi và đáp án, đánh dấu câu hỏi.
- Lịch sử làm bài, điểm trung bình, tỷ lệ chính xác và biểu đồ tiến độ được lưu trên trình duyệt (localStorage).
- Giao diện kính mờ kiểu Uiverse, có chế độ tối và chỉnh cỡ chữ A- / A / A+.
